# Score provenance

A composition, engraving, editorial additions and digital file can have different rights. Public-domain composition status alone does not establish permission to redistribute a particular MusicXML edition.

The bundled library contains 50 original pedagogical miniatures generated by `scripts/generate_library.py` without third-party score data. The generated notation, metadata and motifs are dedicated under CC0-1.0. CATALOG.md lists titles, approximate difficulty, attribution, licence and project source paths. Difficulty bands have not been independently graded.

This is an original exercise collection; a curated 50-piece historical repertoire collection remains incomplete. No third-party score with uncertain edition-specific redistribution rights is bundled. Import a legally obtained single-piano-part MusicXML/MXL or export your own engraving. Imported files remain private on the device.

Future curation must retain exact file URL/revision/hash, transcriber, file-specific licence evidence, attribution and any share-alike obligations. A repository's software licence or a catalogue site's general terms does not establish permission for scores collected from other contributors.
