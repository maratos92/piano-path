# Score provenance and repertoire limitation

The composition, engraving, editorial additions and digital file can have different rights. A public-domain Chopin composition does not prove an arbitrary MusicXML file is redistributable.

## Included

50 original programmatically composed pedagogical miniatures, reproducible from `scripts/generate_library.py`, created for this project without third-party score data. All score notation, metadata and motifs produced by that script are dedicated under CC0-1.0. `catalog.json` and `CATALOG.md` enumerate every title, composer attribution, approximate difficulty, licence and project source path. They are expressly identified as original studies throughout the app.

This is a useful offline exercise catalogue, **not completion of the requested 50-piece curated historical repertoire**. Difficulty bands are approximate and not independently assessed by a teacher.

## Mandatory Chopin works: optional import

- Frédéric Chopin — Waltz in A minor, B.150.
- Frédéric Chopin — Waltz in C-sharp minor, Op. 64 No. 2.

No candidate edition with sufficiently clear file-specific provenance was verified during this build. They are not included, excerpted, or represented by substitute arrangements. Import a legally obtained single-piano-part MusicXML/MXL exported from MuseScore. The app copies it into private app files, indexed by Room and never uploads it.

## Candidate investigated and excluded

https://github.com/mac-marg-pianist/chopin_piano_score_dataset

The repository LICENSE is an MIT **software** licence (copyright KAIST MAC X SNU MARG, 2018). Its README says the team **collected MusicXML scores from MuseScore**. It does not identify the original contributors, edition licences or a chain of permission for each score. The repository-wide software licence alone is insufficient evidence of permission from those engravers. No score data from this repository was bundled.

Music21's Chopin corpus listing offered a mazurka in Kern format, rather than the requested waltzes. The OpenScore organization repositories inspected were Lieder and StringQuartets; neither supplied a verified solo piano waltz edition for this build. This is limited research, not a claim that reusable editions do not exist.

Future curation should record the exact score-file URL, revision/hash, edition/transcriber, licence evidence, attribution text, redistribution conditions and local filename. Retain a licence snapshot, and comply with share-alike licences where applicable. Never substitute a catalogue site's general terms for a file's edition licence.
