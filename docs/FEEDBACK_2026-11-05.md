## Verification and limits

Tests/builds and exact-head CI must pass before publication. New regressions cover chord grouping/ledger lines, cursor-held intervals/rests/hands, rest bounds/pause, full-range ear/triads, default Repeat off, continuous bands and a visible draggable cursor. Browser tests use the actual vendored renderer; Android checks run on phone/tablet emulators. Confirm actual results in the PR/Actions, not this checklist.

Owner acceptance: test 32-note following/chords/extreme pitches and landscape height, cursor drag/zoom/A–B across wrapped systems, pause during loop rest, falling drag and separate scales, accent readability, recent imports/progress, and optional piano reference on a real instrument. Simulators cannot establish BLE/USB output sound, MIDI echo or physical latency. The later full robustness audit and durable signing-key backup remain outstanding.
