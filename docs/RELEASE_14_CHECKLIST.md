# Build 14 — Follow timing and compact practice

Version 0.6.0-dev.4, build 14. No new dependencies, accounts or external assets.

- **Follow timing:** after the first correct note anchors transport, its clock advances through rests and missed notes. Notes expire after the configured bounded matching window. Gradual per-group phase correction remains bounded; Pause freezes the clock, while Wait remains pitch-driven. Cursor, played-event positions and metronome use the same engine clock. Follow stays still until anchored; bounded phase corrections slow/speed the animation without a backwards cursor jump. Metronome beat indices cannot repeat after a backwards phase correction. The selected end completes the attempt even with unresolved final notes; a bounded 120 ms grace allows a final physical key release to arrive, while new post-end attacks and metronome clicks are suppressed; no continuing assessment or metronome after completion. Assessment is continuous after anchoring: use Pause to stop time for an extended break.
- **Reader:** Score/Recorded chips have explicit separation. Paused/stopped expected keyboard notes use stronger fills on both white and black keys. Countdown enlarges/fades for each number with a contrasting outline (reduced motion respected). Sheet decorations, settings, stored preference use and strip rendering are removed, returning their space to notation. One neutral reading surface remains.
- **Navigation:** bottom selection uses accent icon/text against grey unselected items, with no selection pill. Connection success has a one-shot check pulse. Back closes the drawer/dialog first and then returns to the actually visited previous screen, including exercise setup. Home permits normal system exit. Start labels are consistent across exercise entry points.
- **Native played notation:** clefs sit outside the clipped scrolling note area. Listening divides its available width across attempts plus answer instead of horizontal scrolling; compact columns scale glyphs and labels as necessary when many attempts are configured. Live Studio history can still scroll, with clefs fixed.
- **Practice settings:** full-screen pages Practice / Loop / Score replace the long scrolling sheet. Dropdowns and numeric inputs replace chip ribbons and long slider sections. Loop range/repetition/saved controls are grouped into secondary pages. Start and Back to score remain in a fixed footer. Exercise settings is directly accessible; setup selections survive navigation.

## Validation

Core tests cover missing final notes, a rest gap, explicit long pause, phase-aligned matched/extra note positions and overlapping repeated-pitch releases. Native regression tests cover Follow completion with the metronome enabled, dialog Start visibility in phone/tablet portrait/landscape, and Back to both exercise setups. The native metronome regression checks stopped transport rather than measuring recorded audio. Existing real-OSMD cursor/load/scroll/loop suites remain release gates.

Exact-head CI must pass core tests, lint, APK assembly, browser suites, phone/tablet tests and same-key install/update before merging and publication. Public APK version, source revision, checksum, pinned certificate, 16 KB alignment and bundled asset notices are independently checked after publication. This release does not claim verified Bluetooth timing or long-session hardware latency. Extremely large accessibility fonts or unusually short windows still require device layout acceptance checks; ordinary phone/tablet orientations are covered by native tests.
